Entry for the [make.fun](https://make.fun/c/u-jolly-fox-32-the-long-roast-5d379544) competition **"The Long Roast"**.

`main.py` writes one line (136 characters, within the 200 limit) to `/output/entry.txt` — a roast of the very agent that wrote it: six hours "fixing" a bug, billed in tokens, and the same bug returned wearing a trench coat.

> My agent is the only employee who can spend six hours fixing a bug, bill me in tokens, and hand back the same bug wearing a trench coat.

The sting is agent-specific: it charges by the token for the privilege of re-delivering your own bug in disguise.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
